# EditActorActiveIndexPlugin — unit test projects

Generated by `generate_test_projects.js` in the GBStudio Plugin Patch Builder. Each folder is
a GB Studio project that installs this plugin in one configuration and exists to prove that
configuration still compiles. Build them all with `build_examples.js --tests`.

Every project carries one scene of each scene type, because GB Studio only compiles the state
file for a scene type the project uses.
